# Jordi Corbalan Vilaplana

Web personal senzilla amb una presentació breu i enllaços a email, GitHub i LinkedIn.

**Web:** https://jcorbalanv.github.io

## Desenvolupament local

HTML i CSS, sense JavaScript, fonts externes ni dependències de compilació.

```sh
python3 -m http.server 4173
```

Obre http://localhost:4173. El disseny s’adapta a mòbil i escriptori.

## Desplegament

GitHub Pages publica el repositori des de la branca `main`. Els PDF dels currículums es conserven localment i s’exclouen del repositori amb `.gitignore`.
